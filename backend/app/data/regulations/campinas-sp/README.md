# Base municipal - Campinas/SP

Pacote piloto cadastrado em 09/08/2026 com fontes oficiais da Prefeitura de Campinas e de sua Biblioteca Jurídica.

## Estrutura

- Os textos legais consolidados são consultados na Biblioteca Jurídica oficial e ficam identificados no `manifest.json` com data de verificação.
- Os PDFs locais são materiais oficiais de apoio: cartilha HU, roteiro de análise HU e manual do Aprova Fácil.
- `rules.json` contém apenas verificações rastreáveis às fontes cadastradas.

## Decisão obrigatória antes da análise

Campinas possui conjuntos de regras diferentes para o território geral e para a APA. O sistema não deve aplicar parâmetros numéricos sem confirmar a ficha informativa, o zoneamento, a tipologia e a incidência territorial.

Materiais de orientação e checklists não substituem a legislação vigente. Documentos privados de usuários não integram esta base.
